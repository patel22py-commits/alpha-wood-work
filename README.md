# 🪵 AlphaWoodworkingPlan — Official Website & Publishing Platform

A modern, responsive woodworking plans and projects showcase platform built for **AlphaWoodworkingPlan**. Designed specifically for American DIY woodworkers, backyard builders, workshop organizers, and furniture makers, with deep optimization for **Pinterest traffic** and **Google Organic Search (SEO)**.

## 🚀 Key Website Features

1. **Clean Navigation Bar**:
   - **Home** (`index.html`)
   - **Backyard Projects** (`backyard-projects.html`)
   - **Beginner Projects** (`beginner-projects.html`)
   - **Space-Saving Projects** (`space-saving-projects.html`)
   - **DIY Furniture** (`diy-furniture.html`)
   - Search trigger button (`⌘K` / `Ctrl+K`)
   - Pinterest link button

2. **Interactive Blueprint & Specification Modal**:
   - Every project card features a **"View Blueprint & Specs"** button.
   - Clicking it opens an instant, interactive modal displaying:
     - High-resolution project image & dimensions
     - Difficulty level, build time, and estimated USD budget
     - Complete lumber cut lists & hardware shopping list
     - Required hand & power tools
     - Step-by-step numbered build instructions
     - One-click "Pin This Project to Pinterest" button!

3. **📌 Pinterest Integration**:
   - 2:3 vertical pin aspect ratio (1000 × 1500 px) for high visibility on Pinterest feeds.
   - Live encoded share links for instant pinning to user boards.

4. **⚡ Instant Search Engine (`Ctrl+K`)**:
   - Instant live search modal querying across all 24 projects in real time.
